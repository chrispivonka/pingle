    How the clues work

    Light in fiber-optic cable covers about 200 km per millisecond, and a ping has to go there and back. So a 40 ms reply means the server is at most about 4,000 km away. Real cables don't run in straight lines, so the true distance is usually about 60–80% of that limit, which is the band you see on the map.

    Daily hides the server in one of 66 big internet hubs. Hard hides it in a smaller city and lets you ping from about 160. Practice gives you a fresh random server every round and doesn't count toward your stats.

    Reply times are simulated from the real distance between cities, with a fixed routing detour for each pair so the same route always gives the same answer.
